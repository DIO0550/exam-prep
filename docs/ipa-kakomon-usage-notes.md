# IPA 過去問題の利用に関する注意事項

情報処理技術者試験・情報処理安全確保支援士試験の過去問題を、自作の学習サイトで再利用するときに守るべきことをまとめたもの。

> このドキュメントは IPA の公開情報を読んで整理したものであり、法的助言ではない。収益化や大規模な配布を検討する場合は、IPA の試験制度に関する問い合わせ窓口に直接確認すること。

一次ソース:

- [試験に関するよくある質問](https://www.ipa.go.jp/shiken/faq.html) の「試験制度に関するよくある質問 > その他」
- [過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)

---

## 1. 結論

IPA が公表している過去問題は、**許諾の申請も使用料の支払いも不要**で利用できる（法令に特別の定めがある場合を除く）。PDF のダウンロードも問題ない。

ただし無条件ではなく、IPA が挙げる 4 つの留意点を満たす必要がある。

---

## 2. 満たすべき条件

### 2.1 著作権は IPA にある

IPA は著作権を放棄していない。「自由に使っていい」ではなく「条件付きで使用を許諾している」状態。したがって、

- 過去問題のデータを自分の著作物として再ライセンスできない
- MIT / Apache などの OSS ライセンスで問題データを再配布することはできない
- 「パブリックドメイン」「CC0」等の表示をしてはならない

### 2.2 試験制度の意義に反しない目的であること

教育目的での利用が想定されている。学習サイト・問題集・テキストへの使用はこの範囲に入る。

逆に、試験の公正さを損なうような使い方（受験中の不正利用を前提とした機能など）は条件から外れる。

### 2.3 出典を問題単位で明記する

年度・期・試験区分・時間区分・問番号まで書く必要がある。

推奨フォーマット:

```
出典：令和6年度 春期 応用情報技術者試験 午前 問12
```

問題文や選択肢を一部でも改変している場合は、**改変した旨も併記する**。

```
出典：令和6年度 春期 応用情報技術者試験 午前 問12（表記を一部改変）
```

実装上の含意: 出典文字列を後から手で書くのは破綻するので、問題 ID から機械的に生成できるデータモデルにしておく。

```json
{
  "id": "ap-r06h-am-12",
  "year": "R06",
  "term": "haru",
  "exam": "AP",
  "section": "am",
  "no": 12,
  "modified": false
}
```

このキーがそのまま URL・出典表記・ファイルパスの 3 つを兼ねる設計にすると、出典漏れが構造的に起きなくなる。

### 2.4 IPA が公開している PDF 以外の電子データは入手できない

これは「IPA からはデータを提供できない」という意味であって、公開 PDF から自分でテキストを起こすことを禁じたものではない。

ただし後述の技術的保護手段の問題があるので、扱いには注意する。

---

## 3. 実装上の注意点

### 3.1 PDF の制限と、このリポジトリの方針

**実測した事実**（応用情報 午前、令和3年度〜令和7年度の問題・解答 PDF 全 20 ファイル）:

- すべて `/P = -1340` で暗号化されている。印刷は許可、**テキスト/画像のコピーは不許可**
- 例外は 1 つも無い。「制限のかかっていない年度」は存在しない
- **問題 PDF にはテキスト層が無い**。全ページが 1 枚のスキャン画像（`fonts=0`）なので、
  制限の有無にかかわらず `pdftotext` 等で取れる文字は 0。解答 PDF にはテキスト層がある

つまり「制限のかかっていない PDF から通常の手段で抽出する」という道は、この試験区分には
存在しない。

**公式が課している条件**（[FAQ](https://www.ipa.go.jp/shiken/faq.html) の原文）は次の 4 点だけで、
図の利用を禁じる記述は無い。

> - 著作権は放棄していません。
> - 教育目的など、…制度の意義に反しない限り、公表されている過去問題を問題集やテキストに
>   使用される際、許諾および使用料の必要はありません。
> - 出典を以下のように明記してください。（年度、期、試験区分、時間区分、問番号等）
>   また、問題の一部を改変している場合、その旨も明記してください。
> - 公表しているPDF以外の電子データの提供はできません。
>   （PDFセキュリティの解除方法は提供できません。）

最後の 1 行は **IPA 側の提供範囲**を述べたものであって、利用者への禁止ではない（2.4 参照）。

**このリポジトリの方針**:

- 問題文・選択肢は**目視で書き起こす**。PDF のテキスト層を復号して取り出すことはしない
  （そもそもテキスト層が無い）
- **図はページ画像から切り出して使う**。自作の図に差し替えると、描き間違いで問題が成立
  しなくなる事故のほうが重いと判断した。HTML で組んだほうが正確かつ綺麗になるもの
  （表・手順・計算式）は自作する。使い分けは 3.5 を参照
- 正解は解答 PDF から取る
- **解除ツールはリポジトリに含めない**

**残るリスクを明記しておく。** コピー制限のかかった PDF からページ画像を取り出す行為が、
著作権法上の技術的保護手段の回避にあたるかどうかは、利用許諾とは独立した論点として残る。
IPA の FAQ はこの点について何も述べていない。このドキュメントは法的助言ではないので、
収益化や大規模な配布に踏み込むなら、冒頭に書いたとおり IPA の窓口に直接確認すること。
以前のこのドキュメントは「制限がかかっているものは対象外にするか目視で書き起こす」と
書いていたが、図を扱えないと収録できる問題が大きく減るため、上記のとおり緩めた。

### 3.2 ライセンスをコードとデータで分離する

public リポジトリのルートに `LICENSE`（MIT 等）を 1 枚だけ置くと、同梱した問題データまで自分のライセンスで再配布可能だと宣言したことになってしまう。これは 2.1 に反する。

```
LICENSE                 # MIT — ソースコードのみに適用
data/
  LICENSE.md            # IPA 著作物である旨と出典表記義務を明記
  ap/
    r06h/am.json
```

`README.md` にも明記する:

```markdown
## ライセンス

- ソースコード: MIT License
- `data/` 以下の試験問題: 独立行政法人情報処理推進機構（IPA）の著作物です。
  MIT License の対象外であり、再利用する場合は IPA の定める条件に従ってください。
  https://www.ipa.go.jp/shiken/faq.html
```

### 3.3 公式と誤認させない

リポジトリ名・サイト名・ドメイン・OGP・ロゴのいずれにおいても、IPA や試験制度の公式サービスであるかのような表示をしない。

- `ipa-` で始まる名前、IPA のロゴや配色の流用は避ける
- フッター等に「本サイトは IPA とは無関係の個人制作です」と明記する
- 既存の学習サービスを直接連想させる名称も避ける

### 3.4 解答・解説の扱い

- **解答例**は IPA の著作物。出典表記の対象に含める
- **自分で書いた解説**は自分の著作物。ここは自由にライセンスできる
- 午後問題の解答は「解答例」であって唯一解ではない点に、UI 上でも触れておくと親切

### 3.5 図の扱い

図は次の 2 つを使い分ける。判断基準は「どちらが原本に忠実か」で、見た目の好みではない。

| | 手段 | 向いているもの | 改変表記 |
|---|---|---|---|
| **自作** | HTML / CSS | 比較表、手順のフロー、計算式の列 | 要（「図を自作のものに差し替え」） |
| **切り出し** | PNG / WebP | 回路図、状態遷移図、ネットワーク構成図、ベン図などの線画 | 不要（原本のまま） |

自作を選ぶのは、原本が実質的に表や箇条書きで、HTML にしたほうが崩れず読みやすくなる場合に
限る。線画を自作でなぞるのは、描き間違いで正解が変わる事故につながるのでやらない。

ページはスキャン画像なので、切り出しても**ベクタ（SVG）にはならない**。ラスタ画像として扱う。

**第三者著作物**: まれに、問題文中の図表や引用文が第三者に由来することがある。IPA の許諾は
そこまで及ばない可能性がある。該当が疑われる問題は、**収録を見送る**（自作に差し替えても
第三者の著作物である事実は変わらないので、差し替えでは解決しない）。

---

## 4. データソースの将来性

2026 年度から、応用情報技術者試験・高度試験・情報処理安全確保支援士試験は CBT 方式に移行する。

先行して CBT 化された基本情報技術者試験・情報セキュリティマネジメント試験では、移行直後の令和 2〜4 年度分が非公開となり、令和 5 年度以降は「公開問題」という形の限定的な公開に変わっている。

応用情報も同じ経過をたどる可能性がある。つまり**全問が揃った過去問題は令和 7 年度分が最後になるかもしれない**。

含意:

- 既存年度のデータ化を優先する価値が高い
- データモデルに「公開問題（全問ではない）」を表現できる余地を持たせておく
- 収録済み範囲をサイト上で明示し、網羅していると誤解させない
